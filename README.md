# Database Management Project

Šioje repozitorijoje pateikti Duomenų bazių valdymo sistemų (DBVS) laboratoriniai darbai ir praktinės SQL užduotys.

---

## Turinys ir Struktūra

- **SQL Užduotys ir Laboratoriniai:**
  - `3labDBVS_uzduotis.pdf` / `3labDBVS_uzduotis.txt` – Trečiojo laboratorinio darbo užduotys ir SQL užklausos.
  - `4labDBVS_uzduotis.pdf` / `4labDBVS_uzduotis.txt` / `4labuzd.txt` – Ketvirtojo laboratorinio darbo užduotys ir sprendimai.
  - `4_laboratorinis pratimai.pdf` – Papildomi ketvirtojo laboratorinio praktiniai pratimai.
  - `6_labDBVS.txt` – Šeštojo laboratorinio darbo SQL skriptai ir užklausos.
  - `dbvs1lab.pdf` – Pirmojo laboratorinio darbo užduotys (SQL `SELECT` sakiniai, sintaksės klaidos, stulpelių alijaso (`alias`) taikymas, junginiai ir skaičiavimai).

- **Teorija ir Medžiaga:**
  - `DBVS-teorija.docx` – Duomenų bazių valdymo sistemų teorinė medžiaga.
  - `Sujungtos_skaidres.pdf` – Paskaitų skaidrės ir konspektai.

---

## Pagrindinės Temeos ir SQL Funkcionalumas

- **SQL užklausų rašymas:** `SELECT`, `FROM`, `WHERE` sąlygos.
- **Klaidų taisymas:** Sintaksės klaidų ir užklausų optimizavimas.
- **Duomenų formatavimas:** Alijasų (`AS`) naudojimas, tekstinių reikšmių jungimas (*concatenation*).
- **Apskaičiuojami laukai:** Metinio atlyginimo, komisinių ir kitų rodiklių skaičiavimas užklausose.
